# 海龟汤单人原型 V0.1

本机内部体验版，包含阴森氛围视觉、三道既有候选汤、选题配置、正式提问、三层提示、还原弹层、提前揭晓、固定因果复盘、计时与持久化恢复。

当前为**模拟主持**，不调用真实模型，不需要 API Key，不产生模型费用。任意新问法不会被随机判是或否：只有预设问法有固定回应，其余明确告知未判定、不扣次数。还原窗口中的模拟结果按钮只用于流程验收，不代表 AI 能力或玩家成绩。

## 启动

在 Finder 中双击 `启动原型.command`，会启动本机服务并在默认浏览器自动打开游戏。保持打开的终端窗口运行，关闭时按 Ctrl+C。默认地址是 `http://127.0.0.1:8876`，端口占用时会自动换用空闲端口并打开实际地址。

也可以在此目录运行 `python3 server.py`。默认端口被占用会自动选择空闲端口，请以终端打印的地址为准。也可使用 `python3 server.py --port 0`。需要本机 Python 3，无其他安装依赖。

页面不能直接用 file:// 打开：汤底与未公开提示留在服务端，网页通过本机接口获取已经可以公开的内容。

## 建议的体验顺序

1. 在选题页选择档案，调整时间、次数，开始。
2. 点击一个示例问题，再点“提问”。等待期间计时暂停；示例外的新问题会明确告知未判定。
3. 获取提示，检查逐层发布与回看；三层后不再生成。
4. 打开“提交还原”。可以使用“模拟测试工具”检查完整、未完整、关键冲突三种分支；这些是明确指定的模拟结果。
5. 或点击次级入口“查看汤底”，先取消，再确认，体验揭晓、固定复盘和返回选题。
6. 活跃对局中刷新页面，检查记录、草稿与剩余次数恢复。刷新、切后台不暂停时间；系统处理暂停。

局内模拟工具可以让下一次提交模拟超时或非法输出；揭晓确认中可模拟复盘失败。所有反馈仅保存在本机。

## 数据与模型边界

- `public/` 为公开资源。`private/` 为固定故事和主持夹具；HTTP服务不提供该目录。
- 本局记录、草稿和反馈保存在 `runtime/sessions.sqlite3`，此目录不应提交到代码仓库。
- 仅监听 `127.0.0.1`。这是内部原型，不是线上多人服务。
- 真实模型入口当前拒绝请求。已有累计调用额度162次已用满；没有新授权时，不读取密钥或发送提供商请求。
- 本版复盘由固定因果与实际消息组成，没有生成模型的个性化复盘。
- 背景音乐为本项目原创合成的32秒无词氛围片段，不含咳嗽或故事台词；点击开启后播放，可调音量和静音。

## 正式开场与敲门声 V0.6

首次进入本标签页且没有待恢复对局时，展示独立开场。先选择“开启声音体验”或“静音进入”，文字分段呈现“世界上最后一个人坐在房间中，突然响起了敲门声……”。8.2秒演出结束后可进入夜汤，也可随时跳过或按Escape离开。当前标签页刷新不重复拦截，首页底部可“重看开场”。

开场不创建或开始对局，已有对局直接恢复。声音只在用户明确选择后播放，可随时静音、调音量；离开立即停声，不与背景音乐叠放。切后台会暂停，返回后需手动“继续开场”。减少动态效果设置下直接显示全文。音效加载失败时明确提示并继续静音展示。

开场音效由 tools/generate_intro.py 原创合成，包含环境底噪、短暂安静和三次木门敲击，无人声、无音乐。完整记录见 开场音效来源V0.6.json。前端开场逻辑独立于对局主持逻辑。

本轮22项原有程序检查通过。浏览器检查与工具限制见 验收/正式开场验收V0.6.json。
