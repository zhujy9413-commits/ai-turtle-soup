# AI 海龟汤

AI 主持的中文海龟汤项目，目前处于需求梳理、内容样板与人工试玩阶段，尚未开始游戏开发或上线。

本仓库用于备份和版本管理，包含完整汤底、主持资料和试玩复盘。应保持私有；面向玩家使用时，只提取经过审查的公开汤面数据。

## 当前关键约定

- 中文版，面向中国大陆玩家；计划先进行免费邀请码测试。
- 支持单人和多人房间，AI 负责问答、提示、揭晓与复盘。
- 玩家自由讨论与正式提交问题分开；正常是非题回答为「是／否／无关／不清楚」。
- 公开选题展示难度、恐怖强度和必要内容提醒，不预告本格／变格；分类仅留在内部主持资料中。玩家提问时按故事事实回答。
- 已进行的样板试玩是人工对话测试，尚未验证候选模型 API 的效果或成本。
- 游戏制作与上线仍需用户确认。
