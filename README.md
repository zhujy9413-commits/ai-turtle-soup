# 夜汤 · AI 海龟汤

面向中国大陆中文玩家的海龟汤项目，当前游戏名为“夜汤”。目前已有**本机可运行的单人模拟主持原型 V0.6.1**；真实模型自由提问、自由还原、多人房和公网部署尚未交付。

本仓库用于私有备份和版本管理，包含完整汤底、主持资料和内部测试记录，应保持私有。面向玩家的版本只发布已审核的公开汤面和必要资源。

## 现在从哪里开始

- 在本地 `单人原型V0.1/` 双击 `启动原型.command`，保持终端运行，使用打印的本机地址进入。默认地址为 `http://127.0.0.1:8876/`；它不是线上分享链接。
- 当前使用预设示例体验完整流程。页面明确标注“模拟主持”，不需要API Key，也不产生主持模型调用。
- 最新进展见 [2026-10-25 单人原型交付与最新进展](阶段评审/2026-10-25_夜汤单人原型交付与最新进展.html)，视觉与开场约定见 [视觉与开场体验规范 V0.6.1](产品设计/夜汤视觉与开场体验规范V0.6.1.html)。

## 当前已确认的产品约定

- 中文版，先进行免费邀请码测试；后续目标包括单人、多人房、房主权限和搜索匹配。
- 自由讨论与正式提交问题分开，普通是非题使用「是／否／无关／不清楚」。
- 公开选题展示难度、恐怖强度和必要内容提醒，不预告本格／变格。
- 当前原型提供三层提示、独立还原入口、提前揭晓二次确认及复盘，已实现四步教学、独立规则与随时回看汤面。
- 视觉使用灰黑与暗红，页头采用“夜汤”手写字标；正式开场支持有声/静音、音量和跳过，敲击已改用实录剪辑。
- 已有22项程序与接口检查通过。页面和音效体验不等于真实AI主持、多人服务或上线验收通过。
