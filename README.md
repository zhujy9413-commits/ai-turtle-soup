# 夜汤 · AI 海龟汤

面向中国大陆中文玩家的海龟汤项目，当前游戏名为“夜汤”。目前已有**本机可运行的单人原型 V0.9.3**，接入了受调用预算控制的真实问答与还原联调；默认启动仍为模拟模式。生成式复盘、账号、多人房和公网部署尚未交付。

本仓库用于私有备份和版本管理，包含完整汤底、主持资料和内部测试记录，应保持私有。面向玩家的版本只发布已审核的公开汤面和必要资源。

## 现在从哪里开始

- 在本地 `单人原型V0.1/` 双击 `启动原型.command`，保持终端运行，使用打印的本机地址进入。默认地址为 `http://127.0.0.1:8876/`；它不是线上分享链接。
- 默认使用预设示例体验完整流程，不需要API Key。真实模式须显式加载本轮授权文件、配置临时Key并使用独立数据目录；网页不能切换主持模式。
- 当前验证结论见 [2026-10-28最新进展](阶段评审/2026-10-28_夜汤单人原型交付与最新进展.html)。首轮接入历史结果见 [真实主持首轮联调 V0.9.0](单人原型V0.1/验收/真实主持联调结果V0.9.0.html)。此前视觉进展见 [2026-10-26 单人原型交付与最新进展](阶段评审/2026-10-26_夜汤单人原型交付与最新进展.html)，视觉与开场约定见 [视觉与开场体验规范 V0.8.5](产品设计/夜汤视觉与开场体验规范V0.8.5.html)。

## 当前已确认的产品约定

- 中文版，先进行免费邀请码测试；后续目标包括单人、多人房、房主权限和搜索匹配。
- 自由讨论与正式提交问题分开，普通是非题使用「是／否／无关／不清楚」。
- 公开选题展示难度、恐怖强度和必要内容提醒，不预告本格／变格。
- 当前原型提供三层提示、独立还原入口、提前揭晓二次确认及复盘，已实现四步教学、独立规则与随时回看汤面。
- 视觉统一为细宋、灰旧纸档案与克制暗红，保留“夜汤”字标、旧门和钥匙。正式开场支持声音选择与音量，原文停留时钥匙浮现，点击开锁并淡入；V0.8.5不显示跳过开场控件。
- 选中档案以红手印反馈且不跳动，开始栏固定；局内记录独立滚动，可随时回看汤面；剩余15次、5次各提醒一次，三层故事提示独立计算。
- V0.9.0通过52项Python检查和7项次数提醒检查，静音核对了完整流程、网络重试和真实模式界面；此前视觉及开场验收记录保留。页面和音效体验不等于真实AI主持、多人服务或上线验收通过。
- 首次向获邀玩家开放内测预留V1.0；昵称、预设头像、多人形象与外观付费仍属后续范围。
