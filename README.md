# 夜汤 · 公开代码与开发进展

2026-11-01，本次公开同步新增多人房本地流程模块与脱敏进展。项目完整私有维护源为V0.9.5；本次公开导出复用仓库原有单人基础，只增加可公开的房间模块，不把私有开发版本标为完整公开备份。

## 启动本地多人流程

在`单人原型V0.1/`目录运行：

```sh
python3 room_server.py --port 8889
```

通过终端打印的本机HTTP地址访问。可设置昵称和六款预设头像、创建或凭码加入房间、全员准备、共同阅读后计时、讨论、排队提问、共享次数、提示投票、共同揭晓与同步复盘。结算后可返回原房再开一局。

此入口仅监听127.0.0.1，使用预设示例回答，不需要Key，不发送模型请求。它不是公网游戏链接，账号登录、真实AI多人适配、完整匹配和外网部署尚未交付。同一浏览器身份的多个标签页不会变成多个玩家。

## 验证与维护

```sh
PYTHONDONTWRITEBYTECODE=1 python3 run_checks.py
```

本次公开检验结果与范围见[2026-11-01脱敏进展](公开进展/2026-11-01_多人房流程.html)和[机器可读验收摘要](公开进展/2026-11-01_验收摘要.json)。本机完整维护源的268项检查与双身份浏览器流程是内部开发证据，不能替代本次公开导出的独立复验，也不代表真实AI、6人满房或8局并发验收通过。

`rooms.py`组合已有`GameService`处理房间协作，`room_server.py`提供本机房间接口；页面在`public/rooms.html`、`rooms.js`、`rooms.css`，头像在`public/avatars/`。游戏继续保留默认模拟模式，实际付费模型必须另行配置与授权。
