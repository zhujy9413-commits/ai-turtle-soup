# 夜汤 · 原创视觉样张 V0.1

打开本目录的 `index.html` 即可预览；交付时本机预览地址为 http://127.0.0.1:8879/ 。

这是一份供确认视觉方向的独立交互样张。现有单人游戏仍为 V0.8.3，第一轮开放内测继续预留 V1.0。

## 体验方式

- 首页保留“世界上最后一个人……”与老门、钥匙。点击钥匙进入选题。
- 选题可以按场景筛选、搜索、选中档案和调整时间及问答额度。选择不会自动滚到页面底部，开始入口固定显示。
- 开始后，点击示例问题填入输入框，再点击提问，查看预设回应。可以打开规则、回看汤面、逐层获取三层提示及填写还原草稿。
- 顶部导航可直接查看三页；直接点“局内”会放入两轮示例记录。字体开关在同一内容与背景上比较细宋和楷体，字标保持原样。

## 本次视觉选择

门、字标、钥匙、纸张和手印均复用夜汤既有素材。选题像深色档案夹，汤面像摊开的灰旧纸页，推理区保持暗底。暗红集中用于选中手印、肯定回答与关键操作。主体文字用同一字体家族，以字号和疏密区分层级。

细宋为本次候选方案，楷体保留作对照，尚未代替正式游戏的字体决定。对照用控件位于独立样张工具条，不属于未来玩家界面。

## 交互范围

样张完全静音，不创建或修改真实对局，不接模型和后端。时间数字静态展示，未包含正式开场计时和音效；示例提问才有预设回答，其他自由提问不会判定或扣次。还原草稿只保留在当前页内存中，不判断通过与否，刷新后重置。

15次与5次为可检查的提示状态，例如设置16次或6次，再提交一条示例提问。这里没有代替正式游戏已有的计时、扣次和单次提醒逻辑。题库仅三份，不代表几百题性能已完成验证。

## 来源与检查

- 既有素材来源、文件校验及使用边界见 `素材与设计记录.json`。
- 新增细宋取自 [Google Fonts / Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)，字体原文件未修改，保留 SIL OFL 1.1 许可证与 `font-source.json`。本地样张使用完整字体，正式集成时再处理体积。
- 原有楷体来源为 [LXGW WenKai Lite](https://github.com/lxgw/LxgwWenKai-Lite)，保留既有子集和许可证。
- `验收/浏览器验收.json` 保存响应布局和交互检查，`验收/截图` 保存三页电脑图及手机选题、局内图。视口模拟不代替实体手机测试，截图中的浏览器扩展悬浮图标不属于游戏。

如需重新启动预览，在本目录运行 `python3 -m http.server 8879 --bind 127.0.0.1`。
