# 05 AI海龟汤｜商业模式与成本预算

版本 V0.1｜免费内测已确认；商业化为待验证建议｜价格核查日期 2026-10-22。

## 1. 先验证什么，再考虑收费

第一阶段免费、邀请码测试，不实现支付、会员或广告。先验证玩家能否完成公平的推理、是否主动再次玩新题，以及内容和服务能否持续供给。用户已经接受 ¥300／月的初期技术预算，不等于已确认任何售价或盈利预期。

## 2. 用户可能为什么付费

| 付费候选 | 用户购买的价值 | 收费对象／单位建议 | 主要假设与风险 |
|---|---|---|---|
| 主题题包，优先研究 | 经过审校的新题、稳定主持和完整揭晓 | 账号购买题包；多人能否由房主一次解锁整房，需要试验 | 题目容易剧透、解过后价值下降；必须有持续优质供给 |
| 专题组局体验 | 一组适合朋友共同玩的题和氛围 | 一次房间体验或系列题包，由一人发起购买 | 需讲清中断恢复、朋友权限、重复消费与已玩提醒 |
| 会员订阅，暂缓 | 持续更新内容与稳定长期使用 | 按周期订阅 | 尚无更新速度和持续使用证据，不能先承诺每月固定题量 |
| 广告，首版不做 | 作为收入来源而非玩家购买价值 | 广告展示 | 可能打断微恐与推理，不应在没验证价值时插入 |

以上都不是已确定的付费需求。建议先验证题包，再决定是否增加订阅。不能因为模型按 Token 收费，就要求玩家理解或按 Token 购买。

## 3. 免费到付费的候选路径

免费邀请测试 → 确认严重主持错误可控、用户主动回访、供给产能可持续 → 展示真实可交付题包 → 小范围真实购买验证 → 根据购买和售后结果决定扩大或暂停。

口头“愿意付费”、问卷意向、注册量和群内夸奖都不能代替真实付款。现阶段不预估付费率、ARPU、收入、回本月数或获客成本。

## 4. 成本分层与 ¥300 的边界

| 成本层 | 包含内容 | 当前状态 |
|---|---|---|
| 技术固定支出 | 云主机、数据库／备份等 | 候选方案，未购买；实际配置待压测 |
| 随使用变化 | 模型请求、音乐外发流量、邮件、重试与监控存储 | 需要真实计量，不把只显示四个字当作只计四个字 |
| 内容供给 | 创作、审校、事实建模、评测和素材授权 | 不计入 ¥300 技术预算，尚未估算 |
| 开发与运营人工 | 设计、研发、测试、反馈处理和维护 | 尚未估算，不写为免费或零成本 |
| 首次与发布相关 | 域名、服务配置、适用准入核验等 | 单独确认，不能假设都在 ¥300 内解决 |

预算分配建议，待实测与采购报价后调整：主机与备份预留 ¥120、模型预留 ¥100、音乐流量与邮件预留 ¥30、波动缓冲 ¥50，合计 ¥300。此分配尚未单独确认，不是各服务的报价。

统一示例假设：每局累计 50 次调用、每次平均输入 4,000 Token，整局累计输入 200,000 Token、输出 10,000 Token；非思考模式，不计缓存折扣、不含额外重试。50 次包含提问、推理判定、复盘等可能调用，并非每局必定调用次数；预设提示可以不调用模型。

| 场景 | 千问候选 | DeepSeek 对照候选 |
|---|---|---|
| 示例每局模型费 | 0.2×0.2＋0.01×0.8＝¥0.048 | ¥0.24～0.48 |

1,000 局是便于对比的用量情景，不是需求预测。8 局并发代表峰值占用，不代表全天满载；50 账号也不能推出月局数。若同样 1,000 局改用较贵模型，模型费本身可能挤占或超过 ¥300，因此切换模型必须同步重算额度。

每局成本＝Σ（各次输入 Token×实际单价＋各次输出 Token×实际单价）／1,000,000，另计可能的思考、缓存创建、其他计费调用与实际扣费。只记录玩家可见字数无法正确估算。

## 7. 控费机制建议

系统记录真实用量并归因到对局、题目版本、模型版本与失败重试。开局前检查容量与可用预算，为有限时长和次数的当前局预留收尾额度；余额不足则不开新局，不悄悄降低答案质量或突然揭晓。

预算分配比例、预警阈值、预留算法、每账号每日上限及日模型封顶金额，待评测后确认。服务商账单可能滞后，应用限额需留缓冲；¥300 是运营目标，不能仅凭应用计数承诺云账单绝对不会越限。对外测试前验证告警与限流确实生效。

## 8. 盈利判断公式与继续条件

单期经营贡献＝实际收入－支付与退款成本－模型及外发等变动成本－题目和音乐内容成本－服务固定成本－运营人工－获客支出。不能用“收入超过模型费”宣布盈利。

需要补齐的关键输入：每题创作审校工时与可用率、每局真实费用、独立新题的再次游玩、实际购买率、内容更新产能和售后成本。未取数前不提供精确盈亏平衡销量。若用户只愿消费免费经典题，或内容供给成本高于可收取价值，应调整供给方式、定价单位或停止扩大。
